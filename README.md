# Motores 3D: FPS e NPCs

Atividade da faculdade de ago/2023. Publiquei anos depois (nov/2026) e não atualizei nada.

Primeira atividade em 3D. O jogador anda em primeira pessoa (`FirstPersonMovement.cs`) por um terreno com árvores, e um spawner vai criando NPCs que andam pelo mapa (`NPCSpawn.cs` e `NPCMove.cs`).

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.18f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

## Créditos

As árvores são do pacote `laxer tree pkg`, e os modelos e mapas em `Assets/Scene` também são de terceiros.
